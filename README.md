YouTube Clone Project:

This project is a YouTube clone built purely using HTML and CSS. The design replicates the YouTube homepage, focusing on creating a clean and responsive user interface. Key features of the project include:
Flexbox: Used for creating flexible and dynamic layouts, ensuring content adapts properly across different screen sizes.
CSS Grid: Implemented to structure and organize complex layouts like the video grid, allowing for easy rearrangement and customization.
Responsive Design: The layout is fully responsive, meaning it adjusts seamlessly across devices (mobile, tablet, desktop), ensuring an optimal viewing experience.
Modern Styling: I applied custom styles to buttons, images, and navigation elements to make the interface interactive and visually appealing.

This project showcases how HTML and CSS can be used effectively to build a visually rich and user-friendly layout without relying on JavaScript, while maintaining full responsiveness and accessibility.The Youtube FE project is in WDproject.
